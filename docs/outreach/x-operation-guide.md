# X運用ガイド（@cast_log）

**作成日:** 2026-04-09
**対象:** 新規アカウント @cast_log の凍結回避 + 成長戦略

---

## 1日のルーティン（合計5分）

### 朝（2分）
1. タイムラインを30秒スクロール
2. 気になる投稿に いいね 3-5件
3. メーカーの新商品告知があれば いいね + リポスト

### 夜（3分）
1. `docs/outreach/x-post-drafts.md` から当日の下書きをコピペ → 投稿
2. タイムラインで いいね 3-5件
3. フォロー候補リストから 1-3人フォロー（Week 1-2のみ）

---

## フェーズ別ロードマップ

| 期間 | やること | 目標 |

| **Day 30+** | 予約投稿ツール導入検討 | フォロワー100+ |

---

## Day 7 URL追加の判定基準

以下を **全部満たしてから** プロフィールにURL追加:
- [ ] フォロー数 30人以上
- [ ] いいね合計 50回以上
- [ ] 投稿 3本以上
- [ ] フォロワー 1人以上（0人だとbot判定リスク）
- [ ] アカウント作成から 5日以上経過

---

## 凍結回避チェックリスト（毎日確認）

- [ ] 1日のフォロー数が 25人以下
- [ ] 1時間のフォロー数が 10人以下
- [ ] 投稿に外部リンクが毎回含まれていない
- [ ] 同じ文面の投稿を繰り返していない
- [ ] ハッシュタグが3個以下
- [ ] DM を不特定多数に送っていない
