## ⚠️ 注意事項

1. **上記ハンドルは 2026-04 時点の調査結果**。アカウント名変更・凍結等の可能性あり
2. **X で検索して確認してからフォロー**。万が一偽アカウントの場合がある
3. **1日25人以内**（凍結回避）
4. フォロー後に **そのアカウントの直近投稿に「いいね」2-3件** を付ける
5. **Day 1-3 はフォロー+いいねのみ。投稿はしない**
